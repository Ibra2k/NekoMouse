# Description
NekoMouse was really just created since it was something you liked (which is cats) and I guess my gesture of just celebrating on how long it has been. The application is just a cat that sits on your computer that follows your mouse around, and there are a few little things you can do, like change the color of the cat, make it sit/sleep, decrease or increase the delay of its responsiveness based on how long you keep on your mouse still. It isn't much but that is what I was aiming for since I wanted something minimal and not something super hyper optimized, I might add online mode or online chatting later (since I tried but don't have enough time) so live with this.

# Neko Cat

## Controls

- LEFT ALT + Q = Kill the cat process
- LEFT ALT + C = Open color palette to change cat color
- CTRL + S = Save cat color
- LEFT ALT + ARROW RIGHT/ARROW LEFT = Increase and Decrease speed respectively
- LEFT ALT + S = Sit/Stand cat
- CTRL + O = Connect Online (Not working currently)


# Installing NekoCat on Mac

## Step 1: Open Terminal

Terminal will let us run commands and not abide by big tech corp.

1. Press `Cmd + Space` to open Spotlight Search
2. Type `Terminal`
3. Press `Enter`

## Step 2: Download the install script
[Download install.sh](https://github.com/Ibra2k/NekoMouse/releases/download/v1.0/install.sh)

Save it somewhere easy to find, like your **Downloads** folder or **Desktop**.

## Step 3: Navigate to where you saved it

In the Terminal window, type one of the following (depending on where you saved it) and press `Enter`:

If saved to Downloads:
```
cd ~/Downloads
```

## Step 4: Run the installer

Copy and paste this into Terminal, then press `Enter`:

```
chmod +x install.sh && ./install.sh
```

## Step 5: Follow the prompts

The script will walk itself through several steps automatically. Here's what to expect, so nothing catches you off guard:

- **You'll see a lot of text scrolling by.** This is normal — it's downloading and building the app in the background.## Step 6: Open NekoCat

Once it finishes, you'll see a message saying it's installed. From here on, **you never need Terminal again**:

1. Open **Finder**
2. Click **Applications** in the sidebar
3. Double-click **NekoCat**

### If macOS blocks it the first time

You might see a warning like *"NekoCat cannot be opened because it is from an unidentified developer."* This is expected — the app isn't registered with Apple (that costs the developer money each year), but it was built safely on your own Mac, not downloaded pre-made.

To open it anyway:
1. Right-click (or Control-click) the **NekoCat** icon in Applications
2. Choose **Open**
3. Click **Open** again in the popup that appears

You'll only need to do this once — after that, it opens normally.

## Something went wrong?

If Terminal shows red text or the word "error," take a screenshot and send it over — that'll say exactly what happened.hen build as above.
